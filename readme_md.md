# Hola Mundo en Java 🚀

Bienvenido a este repositorio. Este es un proyecto inicial de demostración que implementa el clásico programa "Hola Mundo" utilizando la tecnología Java. Sirve como punto de partida y base de referencia para el desarrollo de aplicaciones más complejas dentro del ecosistema Java.

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** Java (JDK 17+ recomendado / compatible con JDK 8+)
* **Paradigma:** Orientado a Objetos (POO)

---

## 📋 Requisitos Previos

Antes de ejecutar este proyecto, asegúrate de contar con lo siguiente instalado en tu equipo:

1. **Java Development Kit (JDK):** Versión 8 o superior.
2. Un entorno de desarrollo (IDE) como **IntelliJ IDEA**, **Eclipse**, **VS Code**, o simplemente la consola/terminal de tu sistema operativo.

Para verificar si tienes Java instalado, ejecuta en tu terminal:

```bash
java -version
javac -version
```

---

## 🚀 Instalación y Ejecución

Sigue estos pasos para clonar y ejecutar el proyecto localmente:

### 1. Clonar el repositorio

```bash
git clone https://github.com/tu-usuario/nombre-del-repositorio.git
cd nombre-del-repositorio
```

### 2. Compilar el archivo Java

Navega a la carpeta donde se encuentra el código fuente (por ejemplo, `Main.java`) y compílalo:

```bash
javac Main.java
```

### 3. Ejecutar el programa

Una vez compilado, ejecuta la clase generada:

```bash
java Main
```

**Resultado esperado en consola:**
```text
¡Hola, Mundo!
```
